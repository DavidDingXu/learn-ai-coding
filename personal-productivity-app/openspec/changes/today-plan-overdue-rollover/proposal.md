## Why

个人效率助手的“今日计划”如果只看当天任务，会把昨天或更早没有完成的任务漏掉；如果把所有逾期任务一次性塞进今天，又会把一天排爆，用户很快会放弃计划。

这个需求要解决的是一个真实产品问题：每天早上生成计划时，系统既要把未完成的历史任务带回来，又要尊重当天可投入时间，给出可执行的今日清单和明确的顺延列表。

## What Changes

- 新增今日计划生成能力：接收任务列表、计划日期和当天容量，输出今日可执行任务。
- 自动纳入逾期未完成任务，并让逾期任务排在当天到期任务之前。
- 排除已完成任务、阻塞任务和未来任务，避免无效事项污染今日计划。
- 按容量选择可执行任务；放不下的候选任务进入 `deferred`，供后续顺延或提醒。
- 输出已使用时间和剩余时间，便于 UI 展示和后续提醒策略复用。

## Capabilities

### New Capabilities

- `today-plan`: 生成包含逾期顺延、当天任务和容量约束的今日计划。

### Modified Capabilities

- 无。当前项目还没有既有 OpenSpec 能力说明，本次是第一个产品能力规格。

## Impact

- 新增领域逻辑文件：`src/today-plan.js`。
- 新增或更新业务规则测试：`test/today-plan.test.js`。
- 暂不引入 UI、数据库、网络接口和第三方依赖。
- 当前 API 作为领域函数暴露，后续可以被 Web、移动端或后端任务调度复用。
