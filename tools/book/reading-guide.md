# 如何阅读本书

本书适合有编程基础、已经尝试使用 AI 编程的开发者。正文会使用 Git、测试、接口和需求规格等概念；遇到不熟悉的术语，可以先查看书末索引，再回到对应章节。

前两篇帮助建立工作模型和工具工作台。接着依次阅读上下文工程、规格驱动开发、实现与验证，能够形成一条完整工作流。Skill、MCP 和多 Agent 放在这条流程之后，便于判断什么时候需要扩展能力。

本书保留课程原编号：导读、序章 00、正文 01—39 和结语。文中的示例代码、命令、提示文本与输出分别保留原貌；示例输出只说明对应案例，不能代替自己环境中的运行结果。

按主题阅读时，可从篇目扉页进入，也可以使用章内目录和书末术语索引。配套项目用于进一步验证，阅读本身无需先安装 Codex、Claude Code、OpenSpec 或其他工具。工具版本发生变化时，应以项目说明和对应官方文档核对入口。

PDF 使用 A4 版式，较密的宽图独立横排，适合固定版式阅读与打印，EPUB 可随设备调整字号。两种版本均包含完整正文和配图，不依赖联网加载图片；外部文档、源码与问题反馈需要联网访问。
