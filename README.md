## 把一次真实需求做完整

会让 AI 生成代码之后，下一步是什么？这门课程把一次真实需求拆开：理解代码库、准备上下文、写清规格、小步实现，再用测试和审查确认结果。

适合有编程基础、已经开始使用 AI Coding 的开发者。42 篇文章已全部公开，涵盖 Codex、Claude Code 等工具背后的工程方法。

| 你遇到的问题 | 在这里学习什么 |
| --- | --- |
| AI 总是读错代码、改到无关文件 | 上下文工程、代码地图与仓库规则 |
| 需求说清楚了，结果还是不稳定 | SDD、OpenSpec、任务拆分与小步开发 |
| 代码能跑，却不敢交付 | 测试、系统化调试、验证证据与审查 |
| 同样的流程，每次都要重新解释 | Skill、MCP 与个人工程资产 |
